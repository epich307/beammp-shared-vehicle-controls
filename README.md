# beammp-shared-vehicle-controls

Lets every player in a lobby interact with and dride in each other’s vehicles:

Requirements: 

  -BeamNG.Drive 0.40 or above
  
  -BeamMP
  
  -BeamMP server

Installation: extract Client.zip into your server’s Resources/Client/ folder and Server.zip into Resources/Server/, then restart the server.

Not tested on modded vehicles, but it should work.
