

# beammp shared vehicle controls

**Lets every player in a lobby interact with and drive in each other’s vehicles:**
```
Requirements: 

  -BeamNG.Drive 0.40 or above
  
  -BeamMP
  
  -a BeamMP server
```
Installation: extract Client.zip into your server’s Resources/Client/ folder and Server.zip into Resources/Server/, then restart the server.

Not tested on modded vehicles, but it should work.

As far as I know [Hands on the Wheel](https://www.youtube.com/watch?v=AyPVAQ7HUNU) should work perfectly with this mod, but only for the driver seat.
